Both `DataArray` and `Dataset` support positional selection (`isel`) and
label-based selection (`sel`). Both return **new lazy views** — nothing is
fetched until you call `.load()` / `.values()`.

## isel — positional

- An **integer** index picks one element and **drops** that dimension.
- A **slice** `{ start, stop, step }` is half-open and **keeps** the dimension.

<RunnableCell
  title="Integer drops, slice keeps"
  code={`const ds = await openDataset(await makeDemoStore());
const da = ds.get("temperature");   // dims (time, y, x)

console.log("integer:", da.isel({ time: 0 }).dims); // (y, x)
console.log("slice: ", da.isel({ x: { start: 1, stop: 3 } }).dims,
da.isel({ x: { start: 1, stop: 3 } }).shape); // (time, y, x) [3, 2, 2]`}
/>

## sel — by label

`sel` resolves labels through the (eager) dimension coordinate, then delegates to
`isel`. Label **slices** are **inclusive** of both ends.

<RunnableCell
  title="Label lookup and inclusive ranges"
  code={`const ds = await openDataset(await makeDemoStore());
const da = ds.get("temperature");   // x coord is [100, 200, 300, 400]

// Inclusive label range on x -> keeps x = 200, 300
console.log("range:", da.sel({ x: { start: 200, stop: 300 } }).shape); // [3, 2, 2]

// Nearest-neighbour lookup on the decoded time axis
const picked = da.sel({ time: new Date("2000-01-02") }, { method: "nearest" });
console.log("nearest:", picked.dims); // (y, x) — time collapsed`}
/>

Auxiliary coordinates are lazy, so `sel` along them throws — use `isel`, or
`.load()` the coordinate first (see [coordinates](/guide/coordinates/)).

## Selecting across a whole Dataset

`isel` / `sel` on a `Dataset` apply the selection to every variable that has the
named dimension and return a new `Dataset`.

<RunnableCell
  title="Dataset-wide selection"
  code={`const ds = await openDataset(await makeDemoStore());

const step = ds.isel({ time: 0 });
console.log("dims after isel:", step.dims); // time dropped everywhere
step`}
/>
